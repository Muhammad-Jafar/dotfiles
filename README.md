## Dotfiles

This repository provide stored custom configuration files for Arch/Omarchy with Hyprland.

### Built-in apps Replaced by choices

- Nautilus -> [Yazi](https://yazi-rs.github.io/) - TUI file manager
- Alacritty -> [Kitty](https://sw.kovidgoyal.net/kitty/) - Features-rich, fast terminal emulator

### Terminal plugins

- [fzf](https://github.com/junegunn/fzf) (built-in Omarchy) - Quick file subtree navigation
- [ripgrep](https://github.com/BurntSushi/ripgrep) (built-in Omarchy) - File content searching
- [fd](https://github.com/sharkdp/fd) (built-in Omarchy) - Entries finder
- [zoxide](https://github.com/ajeetdsouza/zoxide) (built-in Omarchy) - Replacement for cd
- [eza](https://eza.rocks/) (built-in Omarchy) - Replacement for ls

### other tui tools

- [mapscii](https://github.com/rastapasta/mapscii?ref=terminaltrove) - Maps viewer tui based
- [daylight](https://github.com/jbreckmckye/daylight?ref=terminaltrove) - tracking sunrise and sunset times
- [clock-tui](https://github.com/race604/clock-tui) - windows 11 clock app-like for terminal
- [intelli-shell](https://github.com/lasantosr/intelli-shell) - IntelliSense-like but for shells
- [fastfetch](https://github.com/aristocratos/btop?ref=terminaltrove) - neofetch-like system information tool
- [btop](https://github.com/fastfetch-cli/fastfetch?ref=terminaltrove) - htop-like resources monitor
- [lazydocker](https://github.com/jesseduffield/lazydocker) - Manage docker in terminal
- [lazygit](https://github.com/jesseduffield/lazygit) - Manage git in terminal
- [tuki](https://github.com/hlsxx/tukai?ref=terminaltrove) - Monkeytype-like in terminal
- [euporie](https://github.com/joouha/euporie?ref=terminaltrove) - Jupyter notebooks in terminal
- [mpd](https://www.musicpd.org/) - Music Player Daemon
- [rmpc](https://mierak.github.io/rmpc/) - Rusty Music Player Client
- [yt-dlp](https://github.com/yt-dlp/yt-dlp) - CLI based audio/video downloader
- [cava](https://github.com/karlstav/cava) - Audio visualizer
